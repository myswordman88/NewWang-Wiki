安装指南

手把手教你下载，安装，使用本模组，还配有作者本人制作的系列视频教程

2.1.1 第一步：安装游戏本体
  1. 下载游戏本体

    下载《暗黑破坏神 2：重制版》游戏本体（学习版）。

    [ 传送门 ] 1.4 下载地址（必装内容 中的 游戏本体）

    【注】下载前务必确认游戏本体版本（Ver 3.2.92777）！

  2. 解压缩游戏本体

    解压缩游戏本体，路径不含中文字符可有效避免一些疑难杂症。

    路径范例：E:\Diablo II Resurrected

  3. 不加载 Mod 启动游戏以确认

    安装完成后不加载任何 mod 直接进入游戏，点击 D2R.exe 启动游戏。

    • 目的 1：确认游戏不加载 mod 可以正常运行
    • 目的 2：确认客户端版本，方便和 mod 版本匹配
  4. 调整游戏语言

    第一次解压进入游戏后，很可能是英文版，接下来调整游戏语言。

    • 进入游戏根目录（本范例即 E:\Diablo II Resurrected）
    • 打开 bnet_emu.ini 文件（写字板打开即可）
    • 找到 "Locale=enUS"，表示当前游戏语言是英语
    • 将其改成 "Locale=zhTW"（繁体中文），或改成 "Locale=zhCN"（简体中文）

    【注】还有一行比较相似的内容是 "LocaleAudio=english"，用来控制游戏中的语音，建议不改。

2.1.2 第二步：安装 MOD
  1. 下载与客户端版本匹配的 Mod

    [ 传送门 ] 1.4 下载地址（必装内容 中的 模组下载）

    【注】网盘中会备份往期所有版本，请无视，只需下载最新版一个压缩文件即可！

  2. 解压 Mod 文件

    解压下载的 Mod 压缩文件后，会获得一个文件夹，名为 「NewWang」，里面一共有三个东西：

    • 一个名为 「NewWang.mpq」 的文件（Mod 核心文件）
    • 一个名为 「d2rloader」 的文件夹（插件和补丁，使用方法后面会讲）
    • 一个名为 「使用说明」.TXT 的文件（可以扫一眼）
  3. 找到游戏目录，建立「Mods」文件夹

    找到游戏目录，路径范例 E:\Diablo II Resurrected。

    新建文件夹并命名为 Mods（如果已有该文件夹，可跳过此步骤）。

  4. 将 Mod 文件夹放入「Mods」文件夹

    将第 2 步解压后的 Mod 文件夹放入「Mods」文件夹。

    确认如下目录结构：
    E:\Diablo II Resurrected\mods\NewWang\NewWang.mpq

2.1.3 第三步：下载启动器
  1. 下载启动器

    [ 传送门 ] 1.4 下载地址（必装内容 中的 启动器）

    【注】网盘中会备份往期所有版本，请无视，只需下载最新版一个压缩文件即可！

  2. 解压启动器压缩文件

    解压下载的启动器压缩文件后，会获得一个文件夹，名为 「D2RLoader - 1.1.0 - beta」，里面一共有四个东西：

    • 一个名为 「d2rloader」 的文件夹
    • 一个名为 「D2RCore.dll」 的动态链接库文件
    • 一个名为 「D2RLoader.exe」 的运行程序
    • 一个名为 「d2rloader.mpq」 的文件（启动器所需游戏文件）
  3. 将这四个东西放入游戏根目录

    将这四个东西放入游戏根目录，路径范例 E:\Diablo II Resurrected。

  4. 确保两个运行程序在一起

    确保游戏本体的运行程序 「D2R.exe」 和启动器的运行程序 「D2RLoader.exe」 在一起。

2.1.4 第四步：启动！
  1. 特别说明

    您所下载的「Mod」和「启动器」中隔壁大王都会设置好启动参数，初次使用建议不要修改。

    后续慢慢掌握相关功能后，有一些可调整的空间，可以慢慢摸索。

  2. 启动游戏

    完成以上步骤后，让我们来见证历史：双击 「D2RLoader.exe」 启动暗黑 2「新王觉醒」！

  3. 确认 Mod 是否加载成功

    进入游戏后确认 Mod 是否加载成功（以下几条任意满足一条即说明 Mod 加载成功）：

    • 选择角色界面左侧面板可以看到 Mod 基础信息
    • 进入游戏后打开背包看到背包容量较大且自带魔盒
    • 角色技能面板的文字介绍比原版更为详细

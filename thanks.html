特别鸣谢

向每一位为「新王觉醒」提供灵感、素材、技术支持与陪伴的伙伴与玩家，致以最诚挚的谢意。

每一个版本背后，都站着许多双手。没有他们，就没有「新王觉醒」的今天。这个页面，献给所有帮助过我的人。排名不分先后，感谢不分大小。

1.7.1 赞助人员与玩家

感谢多年来广大的赞助玩家们对我的支持、帮助和鼓励，这是我能坚持到现在的重要原因。

  • 「王者归来」赞助玩家：我的第一个 Mod 的赞助者们，虽然他们现在可能已经退坑了，但是他们对我的支持对模组的赞助成为了后来我能坚持学习制作 Mod 至今的原因之一，因此，我会逐步将「王者归来」中的赞助装备移植到「新王觉醒」中（属性可能会有所改动）。
  • 「魔王降临」赞助玩家：我的第二个栏位的 Mod 的赞助者们，制作了整整三年才堪堪做完全职业技能，期间数位玩家二话不说直接转账说支持我，等做到装备的时候再详谈装备属性，一晃就是数年，感谢这些玩家对我的支持和信任，我会将这些赞助权益移植「新王觉醒」，这次，我全力以赴将它做完！
  • 「新王觉醒」赞助玩家：我的第三个应该也是最后一个融合了我毕生心血的 MOD，在短短半年内 vip 群从寥寥数十人扩充到了数百人，真心感谢你们的支持，成为我每一个夜深人静的夜里喝着红牛肝 Mod 的理由。
  • 「B站粉丝」和「QQ群友」：感谢所有观看我视频尤其是给我一键三连的热情粉丝！感谢在弹幕里热烈气氛，评论里为我指点迷津，私信里给我出谋划策，QQ群里积极 @ 我反馈 BUG 的所有朋友们，你们的每一次互动都让我更有动力去做好这件事。
  • 「夸克网盘」：感谢夸克网盘多年来对我的默默支持，当然，这也离不开使用「夸克网盘」下载我的 Mod 的朋友们对我的支持。
1.7.2 工具与插件作者

感谢制作过程中使用到的模组、工具、启动器、插件、素材及其开发者。

  • Bonesy「D2RLan和D2RHud」：我的 Mod 制作引路人之一，2.4 版本最强大的启动器 D2RLAN 以及插件 D2RHUD 的作者（在 GitHub 上开源分享），同时也是模组「ReModded」的作者，并且在 YouTube 上有两个关于暗黑2重制版 Mod 制作的视频教程（对我受益匪浅）。
  • Dimentio「D2RLoader 作者」：飞机让天空不再遥不可及，D2RLoader 让暗黑2重制版的上限不再受限。
  • Yinyin333333「D2RLoader插件作者」：高产作者，制作了数款极具创意和使用价值的插件和补丁。
  • RuffNecKk「D2RLoader插件作者」：高产作者，制作了社区插件和补丁合集，甚至还是开源的。
  • Ezzstreet「D2RLoader插件作者」：早期社区插件合集作者，也是开源的。
  • Joffreybesos「PrimeMH 地图插件作者」：术士版本最强地图插件的作者，因收到暴雪律师函而停更。
1.7.3 技术支持

从一窍不通的纯小白到现在总算是入了门略有小成的 Mod 作者，一路上离不开众多热心人的帮助。

  • JCK：我的 MOD 制作引路人，最早在 3DM 论坛上正是因为这位大佬的开源 MOD 为我打开了属于我的「真理之门」。
  • YTE：常玩战网的朋友不会陌生吧，YTEMOD 作为战网在线 MOD，把「便利性信息展示」功能做到了炉火纯青的境界，「新王觉醒」的底层显示全部都是使用 YTE 大佬的 MOD 作为基底，感谢 YTE 允许我私自使用这套非常美观而优雅的显示框架。
  • MDK：依然是战网上非常火的 MDKMOD 的作者，其功能丰富性可说是匪夷所思，令人叹为观止，其中各种界面布局改动都非常全面华丽，尤其是装备掉落后的光柱显示更是原了我的一大梦想。
  • 磬风 & 依然：在我摆烂的时间里，两位大佬自发给「王者归来」MOD 制作了非常详尽的游戏内资料查询「凯恩之书」，并且在群里每天热心指导新人解决安装和游玩中遇到的各种问题，正是因为这样「王者归来」这个不成器的 MOD 被更多人了解和体验。
  • 剑所天成：给予我 MOD 制作技术上极大的帮助，同时也是 MOD「剑与自由」「索格伦的荣耀」「剑风幻想」的作者，绝对的技术大佬，推荐大家通过 B站和 QQ 群搜索去了解一下。
  • 黑龙大佬：火炬之光和暗黑2 Mod 作者，从火炬2时代就一直非常崇拜他。几年前在制作「王者归来」期间，我在未获授权的情况下直接使用了黑龙大佬暗黑2 Mod 中的技能图标素材来制作「技能赋予系统」并且没有经过作者本人的同意，后来在 B站粉丝的热心提醒下我才意识到问题，在和黑龙大佬沟通过程中，他非常爽快地允许我使用他导出的几百张图片素材，大大提升了我的制作效率，非常感谢大佬的大度。
  • 恩赐：在制作「王者归来」的过程中提供并指导我制作新地图的工具和资料，帮助我越过整个 MOD 制作中最艰难的一道坎。
  • QQ群的群主们：他们每天热心解答问题，他们每天管理群里的纪律，维护良好的游戏氛围，杜绝修改作弊的相关言论，在我忙着做 Mod 和做「调研」工作时，正是他们作为管理者维持着群里大量玩家的热度，正是这些坚强的后盾可以让我没有后顾之忧安心做我想做的事。
  • 热心道友：总有一些人，他们愿意在 B站上偷偷鼓励你一下，他们会在私信中给我分享对制作 MOD 大有帮助的视频和资料，他们会直接扫码赞助后只留下一句「加油！」，正是因为这样的热心人、好心人，给了我抵御不友好声音的勇气，让我对自己充满信心，感谢你们。
1.7.4 优秀MOD

它山之石可以攻玉，这些 MOD 对我起到了很大的帮助，其他 MOD 作者也可以参考一下。

  • 「ReModded」：Bonesy 大佬出品，加密但不封包，游戏里有很多独特的机制，结合大佬的教学视频，很有学习价值。
  • 「二次出击」：沉淀了好多年的精致 Mod，作者的设计思路非常严谨，装备制作很有创意，是一个玩法非常丰富、平衡性非常优秀的 Mod，值得一提的是它的说明文档我反复仔细看了好多次，也成为了后来我为自己的 MOD 制作几十万字详细在线文档的根本原因。
  • 「东日」：在我所见过的暗黑2重制版开源 MOD 中，技术力绝对的 No.1，我建议所有学习暗黑2重制版 MOD 制作的人都应该去看一看，把这款 MOD 吃透了，你的技术力一定远在我之上，我可以保证。
  • 「兄弟会」：魔电作者之一早年间制作的暗黑2重置版 MOD，可惜由于种种原因是半成品，但是其中依然有很多值得学习的地方，不免让人感叹，不亏是魔电的作者。
  • 「魔电」和「PD2」：这两款暗黑2原版的 MOD（姑且称作为 MOD 吧）至今仍生命力旺盛，定期更新着新的赛季，虽然画面用的是原版，但是其中的内核已经有了很大的改变，如果能沉下心来，我觉得非常值得一玩。
1.7.5 特别的人

最需要感谢的一个人。

做 MOD 是一件非常枯燥的事，尤其在旁人看来是很难理解的一种迷惑行为，试想一下，一个人，对着电脑屏幕，一堆像 excel 一样的莫名其妙的表格，一捣鼓就是十几个小时动也不动，偶尔还在电脑前发出迷之笑声，谁能忍受这种人类迷惑行为发生在身边。

而就是有这么一个人，她一直忍受着我的迷惑行为，不仅如此，甚至还一直鼓励我。看到我整天做 MOD 傻乐傻乐的，她说她很羡慕我，这种精神上的鼓励无疑坚定了我要持续做好这件事情的信念。

这个人，就是我老婆！

谢谢你们，愿意陪我一起在庇护之地里走这么久。接下来的路，我们继续同行。
— 隔壁大王

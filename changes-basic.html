基础改动

经验曲线、掉落率、怪物强度与技能伤害公式全面优化，并对背包、仓库、装备显示、佣兵与 Boss 连战等系统做了大量便利性功能改动。

3.1.1 功能性改动一览

1. 大箱子 + 大背包 + 大魔盒

全面支持无缩放的大箱子 / 大背包 / 大体积赫拉迪姆方块：

  • 玩家的「大背包」容量调整为 15×11，不再进行任何缩放！
  • 玩家的「赫拉迪姆方块」容量调整为 10×10，不再进行任何缩放！
  • 玩家的「个人仓库」和「共享仓库」容量调整为 16×16，不再进行任何缩放！
  • 仓库「通货页面」全面支持 10×10 大容量魔盒，方便合成；除原版设定的符文 / 宝石 / 世界之石碎片堆叠外，还新增「打孔器」/「属性药水」/「技能书」等 Mod 物品。
手柄适配提示：手柄目前只做了背包和佣兵界面适配，仓库页面还未适配，只能显示部分内容，并且手柄界面布局比较“粗糙”，预计后期会彻底重绘。

2. 装备显示 + 吐槽补丁 + 游戏百科

使用了「YteMod」（作者：老顽童，下载自凯恩之角论坛）。

  • 吐槽补丁：大部分装备配备文字说明，评价其定位，帮助新手快速了解作用、使用场景与价值。
  • 更全的装备属性显示：大部分底材会标注对应有价值的暗金 / 套装与评级；在游戏界面点击右下方「+」号按钮或快捷键「H」查看详情。
  • 武器额外显示攻击范围 / 攻击速度 / 装备孔数；防具额外显示基础防御 / 速度修正 / 装备孔数。
  • 游戏内置「百科全书」：点击玩家 HUD 界面中间的「书本」图标，打开「凯恩之书」即可在游戏中查询合成公式 / 符文之语 / 暗金装备属性 / 套装装备属性 / 底材信息等等。

3. 佣兵加强 & 佣兵全装备

  • 佣兵现在可以装备手套 / 腰带 / 鞋子 / 戒指×2 / 项链。
  • 佣兵数值强化：基础生命 / 生命成长 +100%；基础防御 / 防御成长 +200%；基础命中 / 命中成长 +200%；基础力量 / 力量成长 +100%。
  • 雇佣兵招募界面能正确显示新增的灵气；雇佣兵属性页面能正确显示新增技能（上限 5 个，还有一个空位）。
  • 基础敏捷 / 敏捷成长 +100%；基础伤害 / 伤害成长 +100%（由于属性翻倍，实际伤害数据提升量大约在 200%）。
  • 佣兵技能改动：原有技能全部保留，额外新增灵气或被动技能。
  • 第一幕 弓箭手（罗格）：主手可装备十字弓，副手可装备弓矢 / 弩矢（即「箭袋」）；噩梦提供「活力灵气」/「冥想灵气」（等级 10 / 18，基于佣兵等级），地狱提供「专注灵气」（等级 12）。
  • 第二幕 枪兵米山：地狱提供「庇护灵气」（等级 18）。
  • 第三幕 铁狼法师：噩梦提供「火抗灵气」/「冰抗灵气」/「电抗灵气」（等级 8 / 18），地狱提供「拯救灵气」（等级 12）；另为测试需要，噩梦和地狱铁狼均携带被动技能「钢铁之肤」。
  • 第五幕 野蛮人：噩梦提供「力量灵气」/「活力灵气」/「圣火灵气」（等级 8 / 18），地狱提供「圣电灵气」（等级 18）。
此界面暂时只能显示雇佣兵的前三个技能（未来可能会重绘该界面）。「Boss 连战」系统详细介绍见下节「角色 UI」。

4. Boss 连战系统

  • 所有难度下的所有关底 Boss 死亡后会自动复活若干次。
  • 复活后的 Boss 会略微变强（生命 / 防御 / 命中 / 物理伤害增加），且死亡时会掉落物品。
  • 现在所有关底 Boss 的非首杀染色率下调至原版数值；复活的关底 Boss 可以掉落属性药水 / 技能书 / 打孔器（注意难度要求）。
  • 以上数值调整不影响「恐怖地带」的关底 Boss。

3.1.2 界面和外观改动一览

1. 角色 UI（关底 Boss 连战）

  • 增加迷你血条功能（点击闪光的戒指开启或关闭）。

2. 角色皮肤

女巫和刺客的贴图适当美化。

3. 怪物 UI

  • 怪物血条修改为更美观的哥特式。
  • 恐怖地带的「使者」现在会高亮显示，并且名字中显示等级。
  • 现在「恐怖使者」头上会有文字显示，让玩家更容易发现他。

4. 系统 UI

自动跳过开场暴雪的 LOGO 动画。

3.1.3 生活质量提升

1. 商店交易改动

  • NPC 交互界面支持左键快速购买，大幅提升物品批量购买效率。
  • 需注意别误操作购买了昂贵且无用的物品。
  • 感谢「YTEMOD」作者【老顽童】强大的技术力支持；感谢 B 站网友「蟹飞耳德」提供的修改方法。

2. 物品显示改动

  • 现在 24 ~ 33 号符文掉落时自带「紫色光柱」，以防止玩家错过而抱憾终生。
  • 「恐怖使者」的名字后面会备注其等级。

3.1.4 数值改动一览

1. 角色数值改动

  • 角色每提升一级获得的属性点数从 5 点提升为 10 点。
  • 角色每提升一级获得的技能点数从 1 点提升为 2 点。
  • 跑动时耐力消耗速度减半。

2. 物品改动

  • 回城书 / 鉴定书 的堆叠数量上限从 20 提升至 200；NPC 处贩卖的基础堆叠数量也大幅提升。
  • 钥匙的堆叠数量上限从 12 提升至 200。

3. 装备改动

  • 所有投掷武器的初始数量和堆叠上限从 200 提升至 500。
  • 现在所有项链都可以打 1 个孔（镶嵌时视为「盾牌」）；所有戒指都可以打 1 个孔（镶嵌时视为「武器」）。
  • 现在所有手套可以打 1~4（关联装备等级）个孔（视为「武器」）；所有腰带可以打 1~2 个孔（视为「防具」）；所有鞋子可以打 1~4 个孔（视为「防具」）。
  • 咒符（背包里的板板）现在拥有稀有品质。
  • 阿卡拉以跳楼价贩卖「赦免徽章」（洗点道具）——考虑到之前「无限洗点」需要加命令行参数略有门槛，此处再给一个毫无门槛的洗点方式方便新人。
  • 全新箭袋制作：现在「箭袋」作为一种装备，也拥有魔法 / 稀有 / 暗金 / 套装品质（暗金和套装品质箭袋暂未实装）；所有箭袋附带 100% 不消耗箭矢的词条；根据物品等级可打 1 / 2 / 3 个孔。

4. 技能改动

  • 德鲁伊在变形状态下可使用本职业所有技能及「传送术」。
  • 所有「箭袋」支持 StaffMod，即可能出现 + 某个亚马逊技能等级的词条。
  • 通用改动：现在城镇内可使用技能「传送术」；所有角色出生自带一个传送技能「失落的传送术」，初始消耗 20 点法力，冷却 10 秒，每提升 10 级冷却减少 1 秒。
  • 术士：「死亡印记」传送的恶魔数量上限从 3 增至 25；「血沸」触发的恶魔数量上限从 3 增至 25；召唤的「恶魔仆从」头像可正确堆叠显示；召唤恶魔上限为 3 只 + 1 只 / 每 5 点「恶魔专精」等级；适当提高束缚恶魔成功几率（基本几率约 +100%），且洗点时不会消失。

5. 掉落改动

  • 装备掉落：全局暗金染色率提高（约 +100%）；全局稀有染色率提高（约 +50%）；全局超强装备掉率提高（约 +100%）。
  • 符文掉落：符文全局掉率增加 25%（原刷一局牛场期望 4 个，现期望 5 个）；全面调整各符文爆率分布，大幅提高高级符文掉率（#24~#33 约 10 倍左右，略低于「王者归来」）。
  • 物品掉落：红门钥匙掉落几率提高 100%。
  • Boss 掉落：所有关底 Boss 永久首杀掉落；噩梦及以上难度的关底 Boss 均有几率掉落「打孔器」；综合掉率约噩梦 1.74% / 地狱 3.45%（Roll 7 次）；「属性药水」和「技能之书」掉率等同于「打孔器」。
  • 终局掉落：所有「世界之石的碎片」全局爆率提升 200%（即原来 3 倍）；「恐怖使者」额外掉落「打孔器」与终局野蛮人召唤材料（塔力克的痛苦 / 科里克的痛楚 / 马道克的愤怒 / 布尔凯索的噩梦 / 沃鲁斯克的终结）。

6. 怪物 / 难度改动

  • 地狱难度下所有地图精英怪的数量上限提高 100%。

7. 其他改动

  • 怪物密度：普通难度增加 100%（即原来 2 倍）；噩梦难度增加 200%（即原来 3 倍）；地狱难度增加 300%（即原来 4 倍）。
  • 终局改动：恐怖地带击杀精英怪获得充能的几率从 2% 提升至 6%；每只怪物消耗充能升级为「恐惧使者」的几率从 1% 提升至 3%；「恐惧使者」NoDrop 几率从 23899 减少至 5899（破免板掉率从 1/240 提升至 1/60，至少需 4 级或以上恐惧使者才掉落）；目测刷取破免大板效率提升 60~80 倍。
  • 召唤「超级大菠萝」的方式增加：现在除贩卖「乔丹之石」外，也可贩卖「30~33 号符文」召唤超级大菠萝。
  • 药剂与杂项：所有职业使用血瓶 / 蓝瓶的回复加成取消，回复量增加 100%，回复时间统一为血瓶 8 秒、蓝瓶 5 秒；血瓶回复量从 30/60/100/180/320 增加为 45/90/200/360/800；蓝瓶回复量从 20/40/80/150/250 增加为 30/60/160/300/700；所有职业耐力值不再受体力值加成，升级后不再增加耐力值，NPC 不再售卖体力药剂；回城书和辨识书最大堆叠从 20 增加为 100；关底 Boss 首杀常驻（安达利尔 / 都瑞尔 / 墨菲斯托 / 迪亚波罗 / 巴尔每次击杀掉落均与首杀相同）。
  • 游戏物品：现在游戏中所有装备均可打孔并镶嵌宝石或符文；腰带最多 2 孔、手套和鞋子最多 4 孔；戒指和护身符最多 1 孔；噩梦和地狱难度关底 Boss 均有几率掉落「属性药水」和「技能之书」。
  • 属性药水：使用后获得 5 点属性点数（力量 / 敏捷 / 体力 / 智力），使用上限 100 次。技能之书：使用后获得 1 点技能点数，使用上限 100 次。

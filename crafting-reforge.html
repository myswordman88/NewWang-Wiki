重铸与无形化

重铸刷新属性、无形化提升基础——装备打造的两大核心机制。

6.3.1 重铸系统

重铸简介

重铸本质是一种重新获取该装备的机制「魔法」和「稀有」品质的装备重铸后属性完全随机Roll，仅保持底材不变「暗金」和「套装」品质的装备基于游戏机制词条固定，仅改变词条的 <数值>

重铸公式

底材品质重铸配方重铸结果
魔法1件任意 魔法 装备 / 咒符 / 珠宝 + 1「暗金之尘」重新获得该 魔法 装备（属性重新Roll）
稀有1件任意 稀有 装备 / 咒符 / 珠宝 + 2「暗金之尘」重新获得该 稀有 装备（属性重新Roll）
套装1件任意 套装 装备 / 咒符 / 珠宝 + 2「暗金之尘」重新获得该 套装 装备（属性重新Roll）
暗金1件任意 暗金 装备 / 咒符 / 珠宝 + 3「暗金之尘」重新获得该 暗金 装备（属性重新Roll）

暗金「咒符」暂时不能重铸（地狱小护身符和火炬还得自己刷刷刷）

重铸材料

新增物品「暗金之尘」，用于重铸 魔法 / 稀有 / 暗金 / 套装 物品

分解材料产物
4件任意 暗金 装备 + 1 融冰药水（阿卡拉处购买）1「暗金之尘」+ 1 融冰药水（融冰药水返还）
6件任意 套装 装备 + 1 融冰药水（阿卡拉处购买）1「暗金之尘」+ 1 融冰药水（融冰药水返还）

6.3.2 装备无形化

无形化简介

现在玩家可以利用合成公式来将对应的装备转化为「无形」品质以提升基础属性

无形化公式

合成配方转化几率说明
1件 任意品质 装备 + 1「英雄旗帜」10%该装备转化为「无形」装备且保留所有属性
1件 任意品质 装备 + 2「英雄旗帜」25%该装备转化为「无形」装备且保留所有属性
1件 任意品质 装备 + 3「英雄旗帜」45%该装备转化为「无形」装备且保留所有属性

「箭袋」类物品（包括「弓矢」和「弩箭」）均无法转化为「无形」

【注意】：保底机制它来了！每使用1个「英雄旗帜」装备上会显示：「使用旗帜次数」：X次当该词条到达或超过10时，即装备上显示：「使用旗帜次数」：10次（或更多）下一次只需1 个「英雄旗帜」就可使装备必定转化为「无形」以保底形式转化为「无形」的装备可获得全新词条「非酋的执着」（携带后角色头顶有特殊效果）

无形化材料

现在所有「关底BOSS」和「恐惧使者」都有几率掉落「英雄旗帜」（掉落几率等同于 打孔器 / 属性药水 / 技能之书）
